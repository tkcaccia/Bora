# Bora manuscript working draft

The Word file in this folder is the 8 November 2026 working Nature Methods draft. It is not submission ready.

Its revised Benchmark 1 analysis produced audited masks for all 106 previously inspected development evaluation images. The diagnostic mean macro IoU is 0.150 with a historical fastPLS model trained under a different tile rule. The earlier comparator results use a different, frozen protocol and remain labelled as historical. A newly locked, case-separated evaluation and a corrected training contract are still required.

The embedded tissue figure is from the public 10x colorectal H&E example. This draft does not embed Brendon or other restricted user-supplied slide images. The local Word-specific layout check is pending because the bundled document renderer is incompatible with the current host library; a 12-page local visual preview was inspected.
